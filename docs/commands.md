# Commands

Available commands for building, running, and maintaining the project.

## Development

| Command              | Description                             |
| -------------------- | --------------------------------------- |
| `pnpm run start:dev` | Runs with tsx watch for hot reload      |
| `pnpm run build`     | Compiles TypeScript to dist/            |
| `pnpm run start`     | Builds and runs from dist/ (Production) |

## Code Quality

| Command                  | Description             |
| ------------------------ | ----------------------- |
| `npx eslint .`           | Run ESLint on all files |
| `npx prettier --write .` | Format all files        |
